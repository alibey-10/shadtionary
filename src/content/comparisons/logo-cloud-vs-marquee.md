**Logo cloud** and **marquee** both show peer logos as ambient social proof on marketing pages. They differ in motion and scale: a logo cloud is a **static, scannable set**, while a marquee is a **continuous loop** for sets that outgrow a quiet row. Picking one is about whether the list should settle for reading or keep moving so a long roster fits a short band.

## Key differences

| | **Logo Cloud** | **Marquee** |
|---|-----------|----------|
| **Motion** | Static — logos sit still | Continuously scrolling loop |
| **Best set size** | Short, curated (roughly 4–12) | Large or open-ended lists |
| **How you scan** | Full set visible at once | Items enter and leave the viewport |
| **Typical content** | Client, partner, or integration marks | Logos, quotes, chips, or media |
| **Also called** | Logo grid, trusted-by, brand showcase | Ticker, infinite scroller, logo ticker |

## Common use cases for Logo Cloud

A **quiet brand strip** where every mark should be readable without chasing motion:

- **Landing and pricing heroes** — "Trusted by" rows under the CTA
- **Integration showcases** — a fixed set of tools the product connects to
- **Partner or sponsor strips** — conference or agency backers in a grid
- **Customer proof sections** — logos of companies using the product when the list is short

## Common use cases for Marquee

A **looping band** when the roster is too long for a static cloud:

- **Long logo and partner rows** — many brands that would overwhelm a grid
- **Testimonial shelves** — short quotes that keep moving in a compact section
- **Announcement or news tickers** — lightweight headlines across a header band
- **Tech or tag clouds** — skills, stack badges, or category chips in a continuous ribbon
